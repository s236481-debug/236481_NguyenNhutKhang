# Hệ thống quản lý món ăn trên nền tảng đám mây

## 1. Giới thiệu
Đề tài xây dựng hệ thống quản lý món ăn sử dụng React, Node.js, Express và MongoDB Atlas. Hệ thống hỗ trợ quản lý thông tin món ăn, tìm kiếm, thêm, xem, cập nhật và xóa món ăn.

## 2. Công nghệ sử dụng
- Frontend: React
- Backend: Node.js, Express
- Cơ sở dữ liệu: MongoDB Atlas
- Quản lý mã nguồn: Git, GitHub
- Đóng gói ứng dụng: Docker
- Lưu trữ Docker image: Docker Hub
- Triển khai: Render

## 4. Hướng dẫn cài đặt
Yêu cầu cài đặt Node.js, npm và Docker Desktop.

### Backend
Di chuyển vào thư mục backend, cài đặt các thư viện bằng npm install và cấu hình biến môi trường trước khi chạy ứng dụng.

### Frontend
Di chuyển vào thư mục frontend, cài đặt các thư viện bằng npm install và cấu hình địa chỉ backend API trước khi chạy ứng dụng.

## 5. Triển khai
Ứng dụng sử dụng MongoDB Atlas để lưu trữ dữ liệu, Docker để đóng gói và Render để triển khai frontend, backend.

Các URL triển khai sẽ được cập nhật sau khi hoàn thành.
